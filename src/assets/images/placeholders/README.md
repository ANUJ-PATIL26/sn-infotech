# Brand illustrations (production)

These are **production website illustrations** for heroes, media blocks, badges, case studies, and icons.

- Regenerated by `npm run generate:svgs` (`scripts/generate-production-svgs.mjs`)
- Tool brand marks live in `*/tools` and `*-tools` and are left as Simple Icons–style logos
- Edit illustration files in place, or re-run the generator after changing labels/accents in source SVGs
- Paths are wired through `image-map.js`, `page-images.js`, and service content modules
