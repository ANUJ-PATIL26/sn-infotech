# Image assets

- **`image-map.js`** — single source of truth for every image `src` / `alt` on the site
- **`placeholders/`** — labeled SVG placeholders (content photography & partner marks)
- **`final/`** — drop production files here (optional) before updating `image-map.js`
- UI icons (sun/moon, social, nav) live in `src/public/icons.js` as theme-aware SVGs

See README **Swapping Images**.
